# @civic-registry/api

Shared versioned public API contracts for the Civic Registry & Transparency
Engine.

This package contains:

- API envelope/error types;
- public registry metadata DTOs;
- public record/search/subresource DTOs;
- JSON/NDJSON/CSV export serializers;
- OpenAPI 3.1 generation.

It contains no Next.js route code and no database access.

See [Public API, SDK, and exports](../../docs/PUBLIC-API.md).
